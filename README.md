# D2R Skills

Agent skills for [D2R Mobile](https://github.com/d2r-mobile/d2r-mobile).

## Available skills

- [d2r-mobile](skills/d2r-mobile/SKILL.md): Build and install D2R Mobile from your own Nintendo Switch game files, with instructions for the Mac/Xcode and shell packaging routes.

## Use

Clone this repository over SSH:

```sh
git clone git@github.com:d2r-mobile/d2r-skills.git
```

The skill is in `skills/d2r-mobile/`. Copy that directory into your agent's skills directory, or open its `SKILL.md` and ask your agent to follow it. Build commands and documentation paths in the skill refer to a checkout of the D2R Mobile application repository.

You must own the game and provide your own game files. This repository contains instructions only.
