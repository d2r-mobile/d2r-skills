## 如何使用

提供自己的参考截图，并说明要解决的问题、允许修改的范围，以及需要保留的内容。例如：

> 使用 $design-reference，根据我的符文之语界面截图，设计一版“选择配方 → 核对材料与底材 → 确认镶嵌”的新交互。保留暗黑石材和旧金属风格，中文清楚，做成精美专业的三步对照参考图。

同样的方法也适用于应用、网站和其他游戏界面。示例展示的是交付形式与视觉完成度；具体风格和交互应服从用户当次需求。
