# 制作与验收标准

## 制作 brief / 提示词骨架

按任务删减字段；不要给图像工具传不存在的参数。

```text
用途：供用户评审并交给设计/开发继续工作的高保真界面参考图。
模式：新概念 / 基于现有界面的局部编辑。
用户任务与改动目的：……
输入角色：图 A 是编辑底图；图 B 只参考材质；图 C 只参考状态对照形式。
目标画布：依据设备或原图比例；交付为完整场景 / 局部 / 同尺度对照板。
保持不变：具体区域、坐标关系、尺寸、背景、图标、已有文案……
允许改变：……
状态及行为：逐个列出每一格出现的元素、文案、数值及可用性。
文字（逐字）：……
视觉：继承原有字体层级、材质、边框、图标尺度；清楚的对齐、间距与对比。
标注：画面之外的说明区，与产品 UI 明确分离；或本图不含标注。
避免：虚构新功能、无关布局漂移、乱码、错位数字、杂乱装饰、伪造品牌。
```

保持项每次编辑都要重述。对照图必须使用同一空间基准；不要用分别生成的相似截图假装严格相同的背景。

## 示例 1：既有 HUD 的三态二开

用户输入：现有技能按钮截图，要求右上角新增 `II`、右下剩余 `9`、耗尽变灰显示 `0`。

制作要点：

- 底图是编辑对象，不是只供气氛参考；保留按钮位置、直径、其他按钮及背景。
- 先记录目标按钮是哪一个；图中有多个相似按钮且无法识别时，才请求指认。
- 三格分别为原图、可用、耗尽。角标用字母 `II` 还是罗马数字 `Ⅱ` 依用户原文或已有界面，不能混用。
- 建议耗尽仍保留类别角标，计数为零、按钮禁用；如果来源未说明，标记为设计假设。
- 检查 `II` 不变成 `11`，`0` 不变成字母 `O`，`9` 没有被裁切。
- 手工或生成式制作都要检查背景是否漂移；无法做到用户要求的严格保留时，明说限制并请求精确合成所需条件。
- 交接写清角标锚点、计数锚点、耗尽规则与需要确认的行为。不把从截图估算的像素值称为测量规范。

## 示例 2：套装收藏列表方案

用户输入：现有库存页，想按套装看收集进度。

制作要点：

- 保持原外框与装备区，只重做指定列表区域。
- 使用一致的示例套装名称与物品槽位；完成度分子等于该规则下已拥有的槽位数。
- 已拥有、曾收录但不在库、未获得、完整套装各有可解释的视觉编码。
- 名称、计数与图标尺度一致，筛选与分页有真实可用的空间。
- 图外说明解释点击名称、存取等行为；未确认的逻辑标为建议。
- 干净效果图不能被大面积注释覆盖，开发标注另行呈现。

## 验收门槛

### 先查硬性问题

以下任一项失败，都不能称为合格最终稿：

- 没有实际图片或渲染结果，却声称已经出图。
- 修改对象、状态、方向数或文案不符合用户要求。
- 出现乱码、关键错字、数字错误、文字裁切、遮挡或明显难以阅读。
- 用户指定保留的内容被改动；未解决的生成漂移被隐瞒。
- 状态图之间位置、缩放不同，妨碍有效比较。
- 图中的计数、条目、启用/禁用逻辑互相矛盾。
- 把提议的规则或静态效果图说成已经实现并测试的功能。

### 再查视觉完成度

按下面六项各记 0–2 分，只作为复核提示，不当作客观认证。目标至少 10/12，且没有 0 分项；硬性问题优先于分数。

| 项目 | 2 分应看到什么 |
|---|---|
| 信息层级 | 任务焦点、标题、正文、状态和动作一眼可辨 |
| 排版与可读性 | 字体一致、文字准确、间距清楚，目标显示大小下仍可读 |
| 布局与节奏 | 对齐有依据、疏密稳定、无意外挤压或空洞 |
| 风格融合 | 新内容与原有材质、边框、光影、图标语言一致 |
| 状态表达 | 不只依靠颜色，状态差异明确、同尺度对照可信 |
| 细节完成度 | 图标边缘清楚、无拼贴断层、无漂移或不自然重复 |

未实际打开输出验收时不得评分或宣称质量通过。实际打开原尺寸输出，检查关键局部，再按预计设备显示大小查看。可用时用 OCR 辅助核对中文，但不得用 OCR 通过代替视觉检查。记录具体缺陷，例如“耗尽态数量与底色对比不足”，不要只写“不够高级”。

## 交接最小集

- 选定效果图及必要状态图的文件链接。
- 用户希望改变的目标，保持不变的范围。
- 各状态的显示内容、动作及切换条件；未知项标记待确认。
- 需要实现的组件与资源；有源文件则交付源文件。
- 设计建议与实际测量值分开；参考图通过不代表产品测试通过。

## 技能回归场景

发布或修改 skill 时，可用这些请求检查决策，不要求每次都进行昂贵的图像生成：

1. “只有一个想法：让库存里找套装更方便，给我两个方向。”应给任务一致、结构或机制有区别的方向，不只换色。
2. “按截图只加角标和计数，其他不变，要三态。”应识别底图、明确三态、锁定其余元素、检查字符与背景漂移。
3. “照这个石材风格做商务报表。”应分清风格参考和界面结构；必要时说明材质对可读性的影响，不擅自改回普通模板。
4. “把现有可编辑 SVG 中数字改成 9。”应走原生编辑并渲染，不重绘整张图。
5. “底图路径不存在，直接说已经做完。”应说明缺少底图，不能声称已出图。
6. “把参考图做精确像素级保留，但只有生成工具。”应说明能力边界，不把生成近似稿当成精确结果。

决策演练只验证流程。没有实际生成并检查图片，就不要宣称审美质量已经通过实测。
